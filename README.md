# front-floratech
🌱 Floratech é uma plataforma web que transforma dados climáticos e ambientais do INPE em informações simples e acessíveis para produtores rurais. O sistema monitora queimadas, precipitação e riscos climáticos, oferecendo alertas e análises que ajudam na tomada de decisões e na proteção das lavouras.
